# 项目文档（docs/）

> 本目录是 [`AGENTS.md`](../AGENTS.md)（精简版 4 节）的**配套详细文档**：把目录结构、内部函数契约、每个模块的业务逻辑从 `AGENTS.md` 里拆出来独立成文。
> 面向接手项目的开发者与编码代理；所有结论都标注了代码位置（`index.html:行号`），可回溯核对。

## 阅读顺序（新人建议）

1. [`AGENTS.md`](../AGENTS.md)（根目录）—— 5 分钟了解项目、约定与红线
2. [目录结构](目录结构.md) —— 先知道代码放在哪
3. **本文件** —— 找到你要改的模块
4. [内部契约](接口列表.md) —— 查函数签名与调参入口
5. 对应的模块业务逻辑文档（见下表）

## 3. 文档可信度约定

- **代码可验证的**（路径、行号、公式、阈值、字段名）：标注 `index.html:行号`，可信度高。
- **平衡/胜率数据**：来自无头模拟（见 [技能与数值 §6](模块业务逻辑/技能与数值.md)），属于**实测记录**；常规对位 50–100 局/方向，弓箭与冰块对位（第 43 条）150 局/方向，仍存在随机波动。
- **出生点**：第 43 条起每局在各自半场随机生成（`spawnSide()` / `faceInward()`），因此单局结果不再由固定站位决定；跨局胜率才是有意义的指标。
- **对局时长**：默认 180 秒，主菜单可选 60 / 120 / 180 / 300 秒；倒计时归零进入决杀（全体每秒 −5% 最大生命）。
- **标注「[推断]」「待确认」的**：是推理结论，动手前请先在浏览器里验证。
