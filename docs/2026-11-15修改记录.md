# 2026-11-15 修改记录

## 1. 桌面端界面重做 + 手机端新功能同步

### 1.1 背景

手机端已按 1024×512 画布重做，并陆续加入 1–6 人、赛季、金币、自定义姓名、赛事结算等。桌面端仍是最早的「1v1 / 2v2 / 3v3」卡片首页和三栏旧样式。本次按用户要求：

- 桌面端改到「首页 + 选人页 + 赛事准备 + 赛事棋盘」全量；
- 手机端已有能力同步到桌面：**1–6 人、赛季、赛事金币、自定义姓名、6v6**；
- 遵循第 91 条：**单机模式不显示金币、不押注**，桌面选人页只保留预测胜率。

### 1.3 桌面端新布局

**首页**

- 左：`MC · 方块对决`、大标题「赛博斗蛐蛐」、`v0.1.0`、玩法说明、金币/赛季统计卡、`by YT_XG`。
- 右：单机模式（1–6 人 / 同时 / 接力）、联机模式（占位）、`S{n} 赛事模式`（8/16 人、抽签、双败）；下方对局时长 1/2/3/5 分钟。
- 金币与赛季在打开首页、选人页操作、赛事结算后由 `deskSyncChrome()` 刷新。

**选人页**

- 顶部人数 1v1–6v6；4–6 人时双方卡片自动切成两列格子。
- 底部保留摘要、上场方式、预测胜率、随机双方、开始对战。
- 单机不显示金币、不押注（第 91 条）。

**赛事准备**

- 三栏：左「参赛选手」两列名单；中「资金 / 8 人 / 16 人 / 开始分配小组 / 自定义玩家姓名 / 退出赛事」；右「物品」3×3 图鉴（A/B 档标签 + 图标）。
- 「自定义玩家姓名」弹层与手机共用 `mcduel.names.v1`，留空随机，保存后同步 `tour.names` 与玩家名。
- 赛事棋盘、结算页、赛程图沿用现有逻辑，统一了圆角、留白、名字颜色；赛程图在面板内居中并按可用高度缩放。
