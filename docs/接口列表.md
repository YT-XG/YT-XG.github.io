# 接口列表（内部函数契约）

## 0. 为什么是"内部契约"

页面只做一件事：`requestAnimationFrame` 每帧调用 `frame(now)`，由它推进 `tick()` 与 `render()`。
所有能力都在一个 IIFE 闭包里，**对外不暴露任何全局变量**（模拟脚本通过临时注入的 `window.__MC` 读取，正式代码里没有）。

页面有三个状态（`phase`）：

| 状态 | 含义 | 进入方式 |
|---|---|---|
| `'menu'` | **主菜单 `#home`**（1v1 / 2v2 / 3v3 / 赛事）或选人页 `#menu`；两者用 `.show` 切换 | 初始状态 / `openMenu()` / `enterPick()` / `Esc` / 「主菜单」按钮 |
| `'fight'` | 对战进行中 | `startBattle()` / 「开始对战」 / `R` |
| `'over'` | 一局结束，结算横幅显示 | `finish()` |

**1v1 指角色数 1v1**：一个角色可以包含多个单位。当前角色池（`index.html:679-715`）：

```js
var POOL = [
  { key: 'duo',   name: '红石块 + 青金石块', short: '红青组合', role: '羁绊组合', units: ['red', 'lapis'] },
  { key: 'spear', name: '长矛',             short: '长矛',     role: '突刺 / 持续伤害', units: ['spear'] },
  { key: 'bow',   name: '弓箭',             short: '弓箭',     role: '远程持续', units: ['bow'] },
  { key: 'ice',   name: '冰块',             short: '冰块',     role: '控制 / 续航', units: ['ice'] }
];
var pick = { A: 'duo', B: 'spear' };
var activeTeam = 'A';   // 当前正在选择的一方
```

**选择交互**：点击中间的「红」/「蓝」大卡（或左右详细信息面板）切换当前选择方；点击底部角色池中的角色，会写入当前选择方，并自动切换到另一方。
