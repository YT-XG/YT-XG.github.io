### 1.1 手机端四屏要点

- **主菜单（图 2）**：左侧「赛博斗蛐蛐 / v0.1.0 / by YT_XG」，右侧三个按钮：单机模式、联机模式（探索中）、S1 赛事模式。
- **单机模式（图 3）**：主菜单、人数 `N v N`（1–6）、同时上场 / 接力、1/2/3/5 分钟、随机双方；双方各 3×2 阵容格；押注 / 胜率 / 开始对战；右下金币；左缘「设置」抽屉、右缘「角色池」抽屉。
- **赛事准备（图 4）**：左侧参赛选手两列；中间资金（全局）、8/16 人、开始分配小组、自定义玩家姓名、主界面、退出赛事；右侧「物品」A/B 档图鉴。
- **分组页（图 5）**：顶部下一场对战卡（双方物品图标 + 名称、比分、预测、押主队 / 开始对决 / 押客队、赢了 2 分打平 1 分）；下方 A/C ↔ B/D 两组轮播（7 秒自动 + 左右滑动），中间资金 / 主界面 / **重开赛事**。

### 1.2 关键实现约定

- **固定画布**：`.mobi-board` 为 `1024×512`，`mobiScale()` 把 `min(vw/1024, vh/512)` 写入 `--ms`，整块 `scale()` 居中 → 所有机型排版位置一致。
- **进入条件**：`mobiIsMobile()`（`max-width:980px` 或 `pointer:coarse`）；桌面加 `?mobi=1` 可预览手机界面，正常桌面流程不受影响。
- **旧页面隐藏**：`body.mobi-mode` 隐藏 `header/.home/.menu/.tour-board/.tour-panel/.foot/.status`；进战斗切到 `body.mobi-battle`，canvas 占满。
- **赛事与赔率**：赛事页期间旧棋盘保留 `.show`（后台赔率 `oddsAlive()` 依赖），只是被 `mobi-mode` 视觉隐藏；小组赛结束 / 进入双败后回落旧 `mobile.css` 赛程与结算屏。
- **金币**：`tour.bank` 与单机押注共用 `coinsGet()/coinsSet()`；单机每点一次押 100，`finish()` 按 `tourOdds()` 赔率结算，平局退回，离开页面退回未结算押注。
- **人数**：`setSize()` 统一夹到 1–6；桌面主菜单仍只展示 1v1 / 2v2 / 3v3。
