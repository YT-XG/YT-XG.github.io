## 3. 遗留 / 待确认

- **分身伤害口径**：当前按「3 只分身各自造成 120% 攻击力、每命中一次各叠 1 层」实现；1v1 中三只近似平行，通常会同时命中同一目标（合计 360% + 3 层）。若需求本意是「三段合计 120%」或「同一目标每轮技能只叠 1 层」，需要回调这里。
- **控住口径**：按项目现有控制词表实现为 `bindT` 定身 2s（只停移动，仍可施法 / 攻击）；BOSS 免疫。若需要完全眩晕（禁止行动），需要新增状态字段。
- **立刻结算的 DoT 范围**：当前包含破伤风、中毒（草）、浸水（水桶）；冰面 DoT 不在 `spearSettleDots()` 内，因为冰面伤害由冰面实体自己的计时器结算。
- **平衡**：n=5 抽样中长矛 68.8%，矩阵整体本身存在倾斜（冰块 75%、草 27.5%）；本次未调整用户给定的 160% / 120% / 170% 与 1 / 4 层数。
- **TTK 提示**：上述 6 组对位中，水桶 / 铁砧 / 草 / 弓箭都在 22–27s 结束，低于项目「平均 TTK 30–40s」的目标区间；原因是三分身全部命中时一轮技能合计 360% + 3 层破伤风。若必须严格守住 30s，建议优先确认「每只分身 120%」是否确实是需求本意，再决定是否改为「三段合计 120%」或「同一目标每轮只吃一次 120%」。

## 12. 冰块重做的遗留 / 待确认

- **陷阱半径**：用户确认取 **160**；技能 CD 4s、陷阱 5s，单个冰块同时最多 2 块。
- **寒冷初始层**：实现为「进入陷阱的那一帧先 +1 层」，因此站满一个 5s 陷阱会到 **6 层**（进入 1 层 + 每秒 1 次）。若需求本意是「进入后满 1 秒才有第一层」，把 `updateIcePatches` 里的 `if (onTrap && !v.coldOn) v.coldAcc = 0;` 去掉即可。
- **终结技结算**：立刻结算一次寒冷**不消耗层数**，且不结算灼烧 / 破伤风 / 中毒 / 浸水；结算使用的是每次叠层时记录的 `coldAtk` 快照。
- **脆弱口径**：`hurt()` 对所有伤害类型（含 DoT、百分比伤害）乘 1.3；决杀 `deathStrike()` 与种子 `hurtSeed()` 不经过 `hurt()`，不受影响。多次领域只刷新 8s，不叠乘。
- **平衡**：冰块总体 36.3%，但对红青 / 长矛明显占优，主要失分来自远程不踩陷阱（大狗 / 铁砧 / 弓箭 / 水桶）。本次完全沿用用户给定数值，未擅自调整；若需拉平，优先调陷阱半径 / 持续时间 / 寒冷每层倍率。
- **种子**：冰面陷阱不再伤害草的种子（旧版冰面 DoT 会）。若需要陷阱也能冻种子，需要单独补 `hurtSeed` 分支。
