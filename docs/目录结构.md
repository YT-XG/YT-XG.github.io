# 目录结构

> 本文是 `AGENTS.md` §2 拆出来的**目录索引**：有哪些文件、每个文件干什么、改东西该去哪。
> 内部函数契约见 [接口列表](接口列表.md)；模块业务逻辑见 [docs/README.md](README.md)。
> ⚠️ 2026-11-6 之前本项目是单文件（全部逻辑在 `index.html` 里）；现在已拆成 `css/` + `js/`，**但仍是零依赖、零构建、双击即开**。

| 文件 | 语言/栈 | 产物 | 谁在用 |
|---|---|---|---|
| `index.html` + `js/*` | 原生 HTML/CSS/JS（经典脚本） | 浏览器直接打开的页面 | 自己演示 / 发给别人试玩 |

> ⚠️ 必须写清的事实：
> - **本目录不是 git 仓库**（无 `.git`），`AGENTS.md` 与 `docs/` **不受版本控制**。
> - 只有 1 个页面，**没有子项目、没有子仓库**，不存在"跨仓库提交"问题。
> - 没有构建产物、没有 `dist/`、没有 `node_modules/`。
> - ⚠️ **不能用 ES Modules**（`type="module"`）：`file://` 下会被 CORS 拦死，双击就打不开了。所有脚本都是经典 `<script src>`，共享顶层作用域。

## 2. 加载顺序（改脚本标签时必须遵守）

`index.html` 底部按下面顺序引入，**顺序错了会 `undefined`**：

```text
00-base.js          定义 cv/ctx/W/H/ARENA/BALANCE，以及空壳 TYPES = {}
  ↓
05-wallet.js        全局金币 / 每日赠送 / 玩家姓名存取（只依赖 localStorage）
  ↓
items/red … bucket  往 TYPES 上挂 10 个物品（TYPES.red = {...}）
  ↓
items/boss/shared.js  BOSS 共用工具（附魔 / 锁血判定 / drawBossBlock）
items/boss/duo.js     红青双子 → 紫晶核心（TYPES.bossred / bosslapis / bosscore）
items/boss/storm.js   雷云巨像 · 风暴之眼（单单位双血 BOSS）
  ↓
items/pool.js       定义 POOL 与 POOL_BY_KEY（角色池）
  ↓
10-core.js          sense/speedOf、状态、addUnit、spawnSide、reset
  ↓
25-field.js         场地环境：食物 / 局部危险区域 / 全场天气（只读 ARENA，不改 ang）
  ↓
20-menu.js          菜单与详情（函数声明，启动时才调用）
  ↓
30-sim.js           规则层
  ↓
40-render.js        绘制层
  ↓
45-icons.js         角色内联 SVG 图标（ICON_SVG / iconSvg，手机端图标用）
  ↓
50-ui.js            帧循环 + 交互 + buildMenu()/openMenu()/requestAnimationFrame 启动
60-tournament.js    赛事模式：tourBuild/tourNextMatch/tourOnRoundEnd/tourRender
70-tour-odds.js     赔率后台模拟：tourOddsKick/tourOddsStop/oddsPump
80-mobi.js          手机端独立界面：mobiInit/mobiRender/mobiTourSync（必须最后加载）
```

## 3. 各文件职责

| 文件 | 放什么 | 不该放什么 |
|---|---|---|
| `index.html` | 页面结构：`<canvas>`、HUD（血条/倒计时/结算横幅）、主菜单标记、脚本清单 | 任何游戏逻辑、任何样式 |
| `css/style.css、css/mobile.css（手机专属，独立文件）` | 全部样式，含 `.app` 的响应式宽度公式（`(100vh - 128px) × 2.15`） | 结构、脚本 |
| `css/mobi.css` | 手机端 1024×512 固定画布的全部样式（`.m-*`），与桌面样式互不影响 | 桌面样式、脚本 |
| `js/05-wallet.js` | `coinsGet/coinsSet/coinsAdd`、每日赠送、`duelNamesGet/Set`、赛季号与「姓名/赛季/排名/分数」成绩存档 | 任何 DOM |
| `js/80-mobi.js` | 手机端七屏渲染、画布缩放、赛事分组轮播 / 小组赛结束 / 淘汰赛 / 结算、姓名弹层（单机不押注、不显示金币） | 战斗规则（复用 `30-sim.js`） |
| `js/00-base.js` | `ARENA_PAD_*` / `ARENA`、`BALANCE`（伤害/速度/减速等公式常量）、`TYPES = {}` 空壳 | 具体物品的数值（那是 `items/*` 的事） |
| `js/items/<key>.js` | **一个物品的全部**：基础数值、`skill`、`passive`、`rage`、`onCast/onTick/onHit/onAttack/onDamaged/onDash`、`draw`；贴图类角色可在文件末尾加载 `assets/` 资源 | 通用规则（放 `30-sim.js`） |
| `js/items/pool.js` | `POOL`（角色 = 1~N 个物品的组合、名字、配色） | 物品本身的数值 |
| `js/items/boss/shared.js` | BOSS 共用工具：`BOSS_ENCHANT` / `bossBasicMul` / `bossSkillMul` / `bossEnchant` / `bossLocked` / `drawBossBlock` | 具体 BOSS 的数值与技能 |
| `js/items/boss/duo.js` | **红青双子三形态**：`bossred` / `bosslapis`（锁血，各 4550 HP）、`bosscore`（合体，5000 HP）、`coreNuke` 终焉一击 | 常规对局逻辑（BOSS 只由 `bossMode` 触发） |
| `js/items/boss/storm.js` | **雷云巨像 · 风暴之眼**：单单位两条血（5500 / 9000）、8 个技能（落雷 / 雷线 / 雷环 / 雷云 / 领域 / 雷墙 / 磁暴牵引 / 连锁雷）、4 个终结技（风暴降临 / 雷牢 / 万雷归一 / 雷神黄昏）、`STORM` 数值表与占位特效（`[FX]` 标注） | 通用 BOSS 工具（放 `shared.js`） |
| `js/10-core.js` | 时间/状态变量、`el` 缓存、`addUnit`、`spawnSide`、`faceInward`、`reset` | 绘制、菜单 DOM |
| `js/25-field.js` | `FIELD` / `FOOD_DEFS` / `WEATHER_DEFS` / `HAZARD_DEFS`、`resetField` / `updateField`、食物拾取与增益、局部区域与天气 debuff、`drawFieldGround` / `drawFieldSky` | 单位技能、主动转向、菜单 DOM |
| `js/20-menu.js` | `buildMenu` / `detailHtml` / `syncPick` / `openMenu` / `beginFight` | 战斗规则 |
| `js/30-sim.js` | `hurt`/`dmgOf`/`speedOf`/`sense`、`move`/`collide`、`cast`/`think`、箭矢/冰面/炸弹/狂暴、`tick`、回合判定 | 任何 `ctx.*` 绘制调用 |
| `js/40-render.js` | 全部 `draw*` 与 `render()`（只读状态） | 修改游戏状态 |
| `js/45-icons.js` | `ICON_SVG` / `iconSvg(key)`：常规角色的内联 SVG 图标（红青 / 长矛 / 弓箭 / 冰块 / 大狗 / 草 / 铁砧 / 水桶；狗奶、咕咕嘎嘎用 `assets/` 贴图），手机端物品图鉴、阵容格、对战卡共用 | 任何游戏逻辑、DOM 操作 |
| `js/60-tournament.js` | 赛事状态机（建赛/分组/循环赛/淘汰树）、`tourRender` 面板、跳过与倍速 | 战斗规则（那在 `30-sim.js`） |
| `js/50-ui.js` | `frame()` 主循环、暂停/倍速/重开、键鼠绑定、启动调用 | 规则细节 |
| `js/70-tour-odds.js` | 赔率后台模拟：`tourOddsKick`/`tourOddsStop`/`oddsPump`/`oddsCollect`/`oddsFingerprint`、缓存与降级 | 战斗规则、赛事编排 |

## 5. 目录与命名约定（新增内容必须遵守）

1. **新增物品 = 新建一个文件**：`js/items/<key>.js`，内部只写 `TYPES.<key> = { ... }`，不要往全局加别的变量（共享作用域，容易撞名）。
2. **注册三件套**：物品文件 → `pool.js` 里登记角色 → `index.html` 里加 `<script>`（顺序在 `pool.js` 之前）。
3. **文件按加载顺序编号**：`00-` / `10-` / `20-` … 新增引擎文件请插入对应编号区间，并在 `index.html` 与本文同步。
4. **不要新增第三方依赖、不要引入构建步骤、不要改用 ES Modules**（会失去双击可运行）。
5. **图形资源**：默认继续用 Canvas 现画（现有角色都是占位绘制）；**野生狗奶**用 `assets/milk.png`、**咕咕嘎嘎**用 `assets/gaga.png` 本地贴图（分别在 `MILK_SPRITE` / `GAGA_SPRITE` 里用相对路径加载，加载失败自动退化为纯色剪影；gaga 绘制时关闭 `imageSmoothing` 保像素硬边）。新增图片一律放 `assets/`，**不得引用外链**，以保证离线双击可用。
6. 新增文档一律进 `docs/`，按 [docs/README.md](README.md) 的索引登记。
7. **新增/删除/重命名文件 → 更新本文**；逻辑变化 → 同步对应模块文档；**任何代码改动 → 追加当天修改记录**。
