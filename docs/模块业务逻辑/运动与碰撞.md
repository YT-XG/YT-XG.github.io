## 1. 模块职责与边界

| 职责 | 说明 | 关键位置 |
|---|---|---|
| 出生摆位 | 每局在各自半场随机取点，朝向指向场内并随机偏转；**不再固定左右两端** | `index.html:967-992`、`index.html:994-1017` |
| 匀速直线推进 | 每帧按 `ang` 与 `speedOf(u)` 移动 | `index.html:1460-1478` |
| 撞墙镜面反射 | 触边后按入射角做镜面反射，再叠加 ±15° 噪声，避免固定对角线循环 | `index.html:1417-1427` |
| 敌方弹性反弹 | 等质量弹性碰撞；**红石狂暴期间可穿透敌方**（只跳过位置分离与弹性反弹，伤害照常结算）；**青金石狂暴期间仍有实体**，照常分离 / 反弹，保留撞击反馈 | `index.html:1478-1558` |
| 友军穿透 | 同队单位只做位置分离 | `index.html:1484-1494` |
| 定身单位 | 抖动期间速度 0、碰撞分离时不移动 | `index.html:722-725`、`index.html:1484-1494` |
| 撞击伤害窗口 | `BALANCE.hitCd`（0.34s） | `index.html:1509-1519` |
| 技能冲刺 | 速度由 `speedOf` 派生；青金石连撞每段由 `onDash` 重新锁定；**冰块 `noTurn` 技能不冲刺、只生成地面陷阱**；**长矛 2026-11-22 重做后技能不冲刺，普攻突刺在起手时锁定方向** | `js/30-sim.js`、`js/items/lapis.js`、`js/items/ice.js`、`js/items/spear.js` |
| 减速光环 | 青金石光环 | `index.html:490-499`（`tick` 调用 `index.html:1673`） |
| 冰面陷阱 | 冰块技能在当前位置生成；敌方进入后减速 30% 并叠寒冷 DoT；不改方向、不推位置 | `js/items/ice.js`、`js/30-sim.js`（`updateIcePatches`） |
| 炸弹 | 红石普攻炸弹 3.0s 引信；敌方单位触碰（单位半径 +12px）立即引爆；爆炸命中叠灼烧 | `js/30-sim.js`（`updateBombs`） |
| 箭矢飞行物 | 直线飞行、不反弹；命中/出界/超时销毁 | `index.html:1247-1298` |

**本模块不做的事**：

- 不做寻路 / 追踪 / 转向；`move()` 里唯一的转向是技能冲刺与撞墙镜面反射。弓箭的技能声明 `noTurn`，发箭也不改 `u.ang`。
- 不结算伤害数值（`dmgOf()`、`hurt()`）。
- 不处理技能冷却：`cd` 在 `tick()` 里递减，归零后由 `think()` 进入 0.16s 蓄力，再由 `updateCasts()` 调 `cast()`；**没有防僵局重置**。

### 3.0 出生点与初始朝向（2026-11-6 第 43 条）

`reset()` 不再固定左右两端，而是每个单位调用一次 `spawnSide(team, r)`：

| 参数 | 值 / 公式 | 说明 |
|---|---|---|
| A 方 x 范围 | `[A.x+70, A.x+0.42w]` ≈ 116–410.6 | 左半场，留 70px 墙边距 |
| B 方 x 范围 | `[A.x+0.58w, A.x+w-70]` ≈ 549.4–844 | 右半场，留 70px 墙边距 |
| y 范围 | `[A.y+70, A.y+h-70]` ≈ 162–404 | 上下各留 70px |
| 同队最小间距 | `r1 + r2 + SPAWN.gap(46)` | 红石块 / 青金石块同时在场时不会出生重叠 |
| 尝试次数 | `SPAWN.tries = 80` | 80 次都失败才退回该半场中心点 |
| 初始朝向 | `atan2(场地中心 - 单位) + rand(-SPAWN.faceSpread, +SPAWN.faceSpread)`（±1.0 rad） | 一定指向场内，并带随机偏转 |

> 中间 16% 宽度（约 410.6–549.4）天然缓冲区，双方出生点不会跨过中线；不需要额外的"不与对手重叠"检查。

**对现有角色开局平衡的影响**：随机出生把"开局站位几何"这个最大的确定性因素打散。第 42 条旧版固定摆位下，冰块单方向胜率出现 0% / 100% 型极端；第 43 条改为随机出生后，三个冰块对位两方向的胜率差缩小到 3–4 个百分点（详见 [技能与数值 §6.5](技能与数值.md)）。随机范围限定在各自半场、且朝向只加 ±1 rad，因此不会出现"开局背对敌人"或"跨半场出生"这类破坏平衡的情况；初始距离仍与角色速度匹配（最远约 728px，最短约 139px）。

### 3.1 撞完仍保持冲刺速度

反弹只改 `ang`，不改速度大小；速度由 `speedOf` 统一计算（`index.html:560-571`）。

### 3.2 狂暴后的速度

- 抖动期：`speedOf` 返回 0，原地。
- 狂暴期：`baseSpeed × (3 + 狂暴秒数 × 0.15)`，上限 ×6（红青相同，600 → 1200 px/s）。
- 狂暴期无冲刺：`think` 的 `st.rage` 守卫拦截（`index.html:1035`），`startRage` 清零冲刺（`index.html:929`）。

### 3.3 CD 与"连续冲刺"

旧版 `tick()` 有"防僵局"：超过 3.2s 没有有效撞击就把全体 `cd` 清零。旧长矛普通撞击无伤害，这个计时器几乎必然触发，导致冲刺刚结束就再次施放。

**现在：**

- `cast()` 设置 `u.cd = skill.cd`；
- `tick()` 只做 `u.cd = max(0, u.cd - dt)`；
- `think()` 在 `cd <= 0` 时施放一次；
- **没有任何代码重置 CD**。

因此旧长矛的冲刺间隔至少为当时的 `skill.cd`（3.4s）。**2026-11-22 重做后**：普攻突刺 3.0s 一次（目标进入 330px 才起手），技能 7.0s 一次且不再冲刺，防僵局逻辑保持删除状态。

## 5. 关键算法 / 阈值

| 项 | 规则 | 位置 |
|---|---|---|
| 当前速度 | 平时 `(dashT>0 ? dashSpeed : baseSpeed) × 食物移速 × 环境减速 × (slowT>0 ? u.slowMul : 1)`；抖动 0；狂暴仍按 `TYPES[key].rage.speedMul` 派生 | `js/10-core.js`（`speedOf`） |
| 位移 | `x += cos(ang)·sp·dt`，`y += sin(ang)·sp·dt` | `index.html:1462-1466` |
| **撞左右墙** | 左墙随机 `ang ∈ (-π/2, π/2)`；右墙随机 `ang ∈ (π/2, 3π/2)` | `index.html:1417-1427`、`index.html:1450-1474` |
| **撞上下墙** | 上墙随机 `ang ∈ (0, π)`；下墙随机 `ang ∈ (π, 2π)` | `index.html:1417-1427`、`index.html:1450-1474` |
| 撞墙特效冷却 | `wallCd = 0.12s` | `index.html:1467-1473` |
| 法向相对速度 | `rel = (vb − va)·n` | `index.html:1522-1526` |
| **弹性反弹** | `va' = va + rel·n`，`vb' = vb − rel·n` | `index.html:1531-1535` |
| 撞击强度 | `impact = −rel` | `index.html:1537` |
| 伤害窗口 | `impact >= impactMin` 且双方 `hitCd <= 0` | `index.html:1540-1545` |
| 定身分离 | `isShaking(a/b)` 为真时不参与位置分离 | `index.html:1497-1507` |
| 狂暴穿透 | `canPassThrough(u, other)`：`rage.phase === 'rage'` 且 `rage.passThrough` 且为敌方 → 跳过位置分离与弹性反弹（`pass` 分支），但 `rel / impact` 仍参与伤害结算 | `index.html:1142-1146`、`index.html:1492-1535` |
| 减速光环 | 距离 < `lapisAura.radius` → `slowT = max(...)`、`slowMul = 0.6` | `index.html:490-499` |
| 冰面陷阱减速 | 圆心距 ≤ `陷阱半径 + 单位半径 × 0.35` → `slowT = max(..., 0.25)`、`slowMul = min(..., 0.7)` | `js/30-sim.js`（`updateIcePatches`） |
| 食物移速 | 南瓜派 ×1.30 / 迅捷药水 ×1.45，持续 6~8s；与技能冲刺、环境减速、`slowMul` 相乘 | `js/25-field.js`、`js/10-core.js`（`speedOf`） |
| 恶劣环境减速 | 天气 / 局部区域写 `u.field.envSlowT = 0.16`、`envSlowMul = min(...)`；离开区域 0.16s 后恢复 1 | `js/25-field.js` |
| 环境推力 | 强风以固定方向 95 px/s 推动位置；泥沼以 80 px/s 拉向区域中心；都只改位置，不改 `u.ang`；`bossImmune` 免疫 | `js/25-field.js` |
| 寒冷层数 / 伤害 | 进入陷阱立即 +1 层，此后每满 1s +1（上限 6）；每层每秒 `0.15 × 施放者 atk`；离开后每满 1s -1，归零前继续结算 | `js/30-sim.js`（`updateIcePatches`） |
| 炸弹爆炸 | 距离 < `radius + v.r` 的敌人吃 `dmg`（当前半径 100 / 伤害 26） | `index.html:1193-1219` |

### 5.1 撞墙镜面反射（2026-11-16）

`wallBounceAngle(u, hx, hy)` 不再按象限取随机角度，而是先做镜面反射、再叠加 ±15°（±0.26 rad）噪声：

- 撞左/右墙（`hx`）：`ang = π - ang`
- 撞上/下墙（`hy`）：`ang = -ang`
- 角落同时撞两墙：连续执行两次反射（等价于 `ang + π`）
- 最后 `+ srand(-0.26, 0.26)`，避免每局轨迹完全一样（用可复现随机流）

镜面反射让"打一杆、看它弹去哪"变得可预测，噪声只负责保留变化；只改 `ang`，速度大小仍由 `speedOf()` 决定，不会因为撞墙加速或减速。

### 5.1.1 固定步长与可复现（2026-11-16）

- `SIM_DT = 1/60`，`frame()` 用 `simAcc` 累加真实时间，只调用 `tick(SIM_DT)`；帧率、倍速只改变每帧跑几步，不改变单步 `dt`。
- 影响胜负的随机（出生点 / 初始 CD / 撞墙噪声）统一走 `srand()`；粒子、震屏、抖动等纯视觉仍走 `rand()`，不会消耗模拟随机流。
- `reset()` 先 `seedSim()` 再生成单位；每日挑战 / 幽灵码通过 `setNextSeed()` 指定 `matchSeed`。
- 命中顿帧只做渲染层的中心放大，不再缩放模拟时间；否则同一 seed 会因帧率不同而分出不同胜负。

### 5.2 等质量碰撞

单位没有 `mass`；交换法线分量（`index.html:1531`），保持"只改方向、不改速度大小"。

### 5.3 狂暴穿透的拆分（2026-11-6）

红石狂暴期间 `canPassThrough` 成立时：

- 跳过位置分离（允许与敌方重叠）；
- 跳过弹性反弹（不修改双方 `ang`）；
- **不跳过伤害结算**：仍按 `rel / impact` 调用 `dmgOf` / `hurt`，长矛冲刺可以正常打到红石。

因此"穿透"只影响运动与碰撞响应，不再等于免疫伤害。

| 项 | 普通碰撞 | 狂暴穿透 |
|---|---|---|
| 位置分离 | ✅ | ❌ |
| 弹性反弹 | ✅ | ❌ |
| 撞击伤害 | ✅（满足 `impact / hitCd`） | ✅（同一套判定） |

### 5.4 箭矢飞行与命中（`index.html:1112-1184`）

箭矢是独立于 `units` 的飞行物数组 `arrows`，**不参与 `move()` / `collide()`**：

| 项 | 规则 | 位置 |
|---|---|---|
| 发射 | `onCast` 调 `fireArrow(u, power)`，从单位中心沿瞄准方向偏移 `r+6` 出生 | `index.html:586-597`、`index.html:1135` |
| 瞄准 | `aimAngle` 用箭速迭代 3 次算提前量，锁定最近敌人的预计位置 | `index.html:1121-1133` |
| 推进 | `x += cos(ang)·speed·dt`；`ang` 发射时锁定，**不追踪、不反弹** | `index.html:1154-1160` |
| 命中判定 | `segDist(目标圆心, 上一帧→当前帧)` < `目标半径 + 箭判定半径`，避免高速箭帧间穿透 | `index.html:1162-1175` |
| 普通箭 | 命中第一个敌人 → `hurt()` → `life = 0`（立即销毁） | `index.html:1174-1175` |
| 强化箭 | 命中 → `hurt()` → 记入 `a.hit`，同一敌人不再结算，继续飞行 | `index.html:1170-1174` |
| 销毁 | `life <= 0` 或飞出 `ARENA` 外 24px | `index.html:1157-1158`、`index.html:1180-1183` |

- 生命 0.95s：普通箭最远约 608px、强化箭约 836px；实际多数箭在命中或出界时提前销毁。
- 箭矢伤害直接调 `hurt()`，因此无敌抖动、护盾、死亡与羁绊流程完全一致。

### 5.5 冰面陷阱（`js/30-sim.js` 的 `updateIcePatches`）

冰面陷阱是贴地的**区域效果**，独立于 `units` 与 `arrows`，不改任何方向、不推动单位：

| 项 | 规则 | 位置 |
|---|---|---|
| 生成 | 冰块技能 `onCast` 在当前位置调用 `dropIceTrap()`；技能 4.0s CD | `js/items/ice.js`、`js/30-sim.js` |
| 形状 / 数量 | 半径 **160** 的贴地椭圆；全局 `icePatches`，上限 `ICE_PATCH_MAX = 120`，超出删最早 | `js/30-sim.js`（`dropIceTrap`） |
| 寿命 | `life = 5.0s`；最后 0.5s 线性淡出（淡出期间仍生效） | `js/items/ice.js`（`trap`）、`js/40-render.js` |
| 生效判定 | 只对**敌方**（`p.team !== v.team`）生效；圆心距 ≤ `p.r + v.r × 0.35`；重叠多块不叠加层数 | `js/30-sim.js`（`updateIcePatches`） |
| 减速 | `slowT = max(slowT, 0.25)`、`slowMul = min(slowMul, 0.7)`；`slowT` 归零后由 `tick()` 恢复默认系数 | `js/30-sim.js`、`js/10-core.js`（`tick`） |
| 寒冷层数 | 进入立即 +1 层，此后每满 1s +1（上限 6）；离开后每满 1s -1 | `js/30-sim.js`（`updateIcePatches`） |
| 持续伤害 | 每层每秒 `hurt(v, 层数 × 0.15 × 施放者 atk)`；层数归零前持续结算 | `js/30-sim.js`（`updateIcePatches`） |
| 生命周期 | `reset()` / `openMenu()` 清空 `icePatches`，避免跨局残留 | `js/10-core.js`、`js/20-menu.js` |

- 减速只写 `slowT / slowMul`，与青金石光环共用同一派生通道（`speedOf`），**不进入 `ang`**。
- 寒冷是**独立于其他 DoT** 的叠层状态：每层每秒结算一次，离开陷阱后每秒衰减 1 层，归零前伤害继续；不会被 `spearSettleDots()` 结算（冰块终结技只结算寒冷）。
- 陷阱只改变速度大小与添减寒冷层数，**不影响转向**，符合「只有技能 / 撞墙才转向」的红线。
- 冰块技能不冲刺、不改 `u.ang`；普攻冰锥是直线飞行物，飞行规则与箭矢一致。

### 5.6 铁砧落点（`js/30-sim.js` 的 `updateAnvilMarks`）

`anvilMarks` 是"延迟结算的圆形区域"，与 `bombs` 同一类，但**完全不参与运动**：

| 项 | 行为 |
|---|---|
| 生成 | `onCast` 调 `spawnAnvilMark(u, e.x, e.y)`，在敌人**当前位置**锁定坐标 |
| 计时 | 每帧 `m.t -= dt`；归零后从数组移除并结算 |
| 结算 | 圆心到单位中心 ≤ `markR + r*0.5` 才命中；最近目标全额、其余 `splashMul`、外圈 `edgeMul` |
| 运动影响 | **不推人、不改 `ang`、不改位置**，只调用 `hurt()` |

- 落点与红石炸弹的区别：炸弹跟随施放者当前位置落地，铁砧落点在**施放瞬间**锁定，之后不随任何人移动。
- 八连铁砧仍是同一套落点：每 **0.32s** 生成一个，每个落点在生成瞬间按目标当前速度重新取一次预判位置，但生成后不跟随；8 个全部释放后才开始读 8s CD。
- 终结技分裂出的铁砧分身是**独立单位**，有自己的 `ang / baseSpeed`，与普通单位一样直线移动、撞墙反弹；分身不会改变本体或敌人的方向。
- 这条实现是「圆形延迟伤害」，不是 Steering：没有任何代码在落点存在期间修改单位的方向或速度。

### 5.7 野生狗奶领域（`js/30-sim.js` 的 `isMilkChannel` / `milkDrain`）

| 项 | 行为 |
|---|---|
| 不可移动 | `speedOf(u)` 在 `u.st.milkT > 0` 时**直接返回 0**；`move()` 不产生位移 |
| 不可推动 | `collide()` 把领域施放者与无敌抖动同列视为固定桩：只推另一方，弹性反弹只改对方 `ang`，施放者朝向不变 |
| 免疫伤害 | `hurt()` 看到 `milkT > 0` 时先扣 **500 点打断护盾**，护盾存在时不掉血；打空立即 `interruptMilk()`，并从**打断瞬间**把终结技冷却重新读满 12s |
| 冷却 | 领域期间 `u.ultCd = 0`（不读 CD）；自然结束时设 `u.ultCd = 12`，被打断时同样设 12；**不能无缝衔接** |
| 不改方向 | 普攻 / 技能均为空，领域由 `onUlt` 展开，期间没有任何代码修改方向 |
| 百分比扣血 | 展开瞬间 + 之后每秒 `milkDrain()`：敌方单位走 `hurt()`、敌方种子走 `hurtSeed()` 按 `maxHp × 7%` 扣；**不推人、不改位置** |

- 这条实现同样**不是 Steering**：引导者自己停住，敌人也不会被吸过来；掉血只是伤害结算。
- 例外一：决杀 `deathStrike()` 不走 `hurt()`，引导者仍按 5%/s 掉血。
- 例外二：1v1 的场地收缩 `updateShrink()` 会把越界单位直接推回场内，站桩者也会被推（属于场地规则，不是自主移动）；2v2 / 3v3 / 赛事 / BOSS 不收缩。
- 例外三：强风 / 泥沼 / 狂浪引力会直接推动位置，但**从不修改 `u.ang`**；它们与「技能是唯一主动转向手段」的红线不冲突。

### 5.7.1 大狗终结技引导（`isDogChannel` / `dogUltLaserTick`）

| 项 | 行为 |
|---|---|
| 不可移动 | `speedOf(u)` 在 `st.ultLaserT > 0` 时**直接返回 0** |
| 不可推动 | `collide()` 把引导者视为固定桩：只推另一方；狂浪引力也不拖拽它（`updateWaves` 跳过） |
| 不普攻 / 不放技能 | `onTick` 在引导期间只推进激光段数；`think()` 直接返回，`canCast` 也返回 false |
| 光束方向 | 光束走 `st.ultLaserAng`，以 **1.2 rad/s** 缓慢追踪最近敌人；**不修改本体 `u.ang`** |
| 段数 | 5 秒 50 段（每 0.1 秒一段）：前 20 段 5% / 中间 20 段 8% / 最后 10 段 12% 攻击力；第 50 段（最后一击）改为 **20%** 并施加灼烧；最后 10 段每段叠 5 层灼烧 |
| 命中减速 | 每段命中：`slowT = max(slowT, 0.6)`、`slowMul = min(slowMul, 0.5)`；命中期间保持 -50% 移速，BOSS 免疫减速 |
| 伤害表现 | `hurt(..., {multi:1})`：每段单独飘字、不合并；`laserStrike` 每段额外画一个小命中环 |
| 结束 | 50 段结算完或阵亡时 `ultLaserT = 0`，光束立即消失；场地收缩仍可推动本体 |

### 5.8 草的种子（`js/30-sim.js` 的 `updateSeeds` / `hurtSeed`）

> 2026-11-22：草已重做为「捆绑 / 生辉光环 / 中毒叠层」，**不再生成种子**。本节保留作为核心召唤物系统的规则说明；没有 `seeds` 时 `updateSeeds()` 直接空转。

种子是**独立血条实体**，不是碰撞体，也不是障碍：

| 项 | 行为 |
|---|---|
| 不参与碰撞 | `collide()` 只遍历 `units`，种子不会被弹开、也不推动任何单位 |
| 不掉移动状态 | 种子没有 `ang / dashT / speed`；它不移动，也不改草的朝向 |
| 旧"踩踏"已删除 | `updateSeeds()` 不再按"敌方贴身 25 点/0.35s"扣血；**普通接触 0 伤害** |
| 谁可以打它 | 只有 `dashT > 0` 的敌方**技能冲刺**、以及箭矢 / 激光 / 铁砧 / 炸弹 / 狗奶 / 决杀（都走 `hurtSeed()` 或直接扣血）；冰面陷阱只作用于单位，不再伤害种子；命中后 `s.flash = 0.22` 闪白，`hitCd 0.35s` 防止同一次冲刺连续结算 |
| 摧毁 | `hp <= 0` 才 `destroySeed()`（碎裂 + 从 `seeds` 移除），**没有其他消失条件** |
| 场地收缩 | `updateShrink()` 把越界的种子 `x` 夹回新墙内（不压碎、不推 y） |

- 种子治疗同样**不是 Steering**：`updateSeeds()` 只在每满 1 秒给 `healRadius = 200px` 内的友方单位 `hp += 5`（不超过 `maxHp`），不改任何 `ang / 位置`。

## 7. 改动检查清单

- [ ] 没有引入任何"朝目标转向/加速"的逻辑
- [ ] 速度读取统一用 `speedOf(u)`
- [ ] 新增定身/无敌状态时，`speedOf`、`hurt`、`collide` 三处都处理
- [ ] 改撞墙反射逻辑后用浏览器验证，确认没有卡墙或反向朝墙
- [ ] 改弹性碰撞后确认撞完是分离的
- [ ] 改 `hitCd` 后跑一局看是否连续跳数字
- [ ] **不要加回"防僵局重置 CD"**，否则长矛会再次连续冲刺
- [ ] 改炸弹后确认同队不被炸
- [ ] 改狂暴穿透后确认只对敌方生效、友军仍做位置分离
