# 秘境试炼（卡牌 Roguelite）模块业务逻辑

> 适用代码：`js/85-adventure.js`、`css/adventure.css`、`index.html`（入口 / 脚本 / 版本）、`tools/simadventure.js`。
> 本文记录 **v26.11.240** 的「双试炼 · 卡牌自走棋」规则。普通 1v1 / 2v2 / 3v3 / 赛事 / BOSS 5v1 不受本文数值影响。

---

## 1. 定位与入口

- 卡牌式单机 Roguelite：10 个角色 × 9 张 = **90 张牌库**，商店三选、3 张自动升星、6 备战 + 3 战斗席。
- 入口在桌面首页 `#homeAdventure` 与手机首页「秘境」按钮；遮罩 `#adventure`（`css/adventure.css`，`z-index:520`）。
- 战斗仍复用 `js/30-sim.js` 的台球式移动、技能、碰撞、伤害与 `hurt()`；秘境只负责「卡牌 / 经济 / 海克斯 / 装备 / 试炼推进」。
- 场地、天气、食物与普通对局共用 `js/25-field.js`；战斗种子由 `run.battle.seed` 固定，R 重开同一场不会换敌人。
- 竖屏打开会被拦下并提示横屏；手机首页按钮文案走 `adventureHomeLabel()`。

### 主菜单隔离（P0）

秘境会临时改写 `teamSize / modeKind / roundDuration / seriesBest / pick / bossMode / bossRoleKey`。因此：

1. `adventureOpen()` 首次打开时用 `advSnapshotMatch()` 快照主菜单状态；
2. 任何回主菜单的路径（× / Esc / `openMenu()`）都会先走 `adventurePrepareMenuReturn()`：
   - 战斗未结束 → `adventureOnMenu()` 回 hub，保存当前节点与商店；
   - 已进入终局慢镜头（`phase === 'over'`）→ 先 `adventureCompleteBattle()` 结算，避免回滚已打完的胜负；
   - 隐藏遮罩、`advRestoreMatch()` 恢复主菜单、清空 `endFx`。

## 2. 数据结构与存档

存档键：`mcduel.adventure.run.v3`；旧 v2 键不再读取，会在清档时一并删除。
`adventure.run` 关键字段：

| 字段 | 含义 |
|---|---|
| `version` | 固定 `3` |
| `env` | 本局环境 id（`ADV_ENVS`） |
| `trial / node` | 当前试炼（1–2）/ 当前节点（1–7） |
| `cleared` | 已抵达/完成的节点计数（0–14） |
| `gold / hp / maxHp` | 金币 / 征战生命 / 上限（初始 24 / 60） |
| `streak / bestStreak` | 当前连胜 / 本局最高连胜 |
| `cards` | 卡牌对象 `{uid,key,star,items[]}`；`star` 1–3 |
| `board` | 3 个战斗席 uid（`null` 为空） |
| `bench` | 6 个备战席 uid |
| `shop` | 当前 3 个商店条目 `{key,star}`，已买为 `null` |
| `inventory` | 装备背包 id 数组（基础 + 进阶） |
| `hexes` | 已获得海克斯 id 数组 |
| `hexUsed` | 每个节点是否已触发过 1-2 / 2-2 的固定海克斯 |
| `extraHexUsed` | 「海克斯狂热」环境在 1-6 / 2-6 的额外海克斯标记 |
| `global` | 全局永久强化 `{hp,atk}`（来自 5 星奖励） |
| `pool` | 牌库剩余张数 `{roleKey: n}`（初始每角色 9） |
| `uidSeq` | 卡牌唯一 id 计数器 |
| `difficulty` | 当前敌难（默认 10，黄金 +2 / 棱彩 +5） |
| `step` | `hub / battle / result / reward / hex / item / defeat / complete` |
| `result` | 最近一场战报（奖励拆分 / 扣血 / 掉落） |
| `pending` | 当前三选一面板（奖励 / 海克斯 / 装备） |
| `battle` | 当前节点敌人快照（重开 / 失败再战复用） |
| `challengeStar` | 1-5 / 2-5 本次掷出的难度星级（1–5） |
| `midasNode` | 「点金术」已结算的节点 key |
| `shopNode` | 商店对应的节点 key，避免重复免费刷新 |

`advEnsureRunShape()` 在读取时补齐字段并清理失效 uid；任何写操作都走 `advSave()`。

## 3. 环境（开局三选一）

`ADV_ENVS` 共 6 个，开局随机展示 3 个：

| 环境 | 效果 |
|---|---|
| 彩虹时代 | 本局所有海克斯都是棱彩品质（每个棱彩仍 +5 敌难） |
| 和平契约 | 敌人难度 -4（对普通敌人与 BOSS 都生效） |
| 海克斯狂热 | 1-6 / 2-6 额外获得一次海克斯三选一 |
| 富饶之地 | 开局 +15 金币，利息上限 +2 |
| 铁匠的馈赠 | 开局 2 件基础装备，装备掉落率 +20% |
| 试炼枷锁 | 敌人难度 +2，金币奖励 +30% |

## 4. 试炼结构

两个试炼各 7 个节点；第二试炼沿用同一套节点类型，但敌人基础强度更高、最终 BOSS 换成雷云巨像。

| 节点 | 类型 | 内容 |
|---|---|---|
| x-1 | 奖励关 | 1 血小怪；胜利后奖励三选一 |
| x-2 | 奖励关 | 2 血小怪（每个 1 血）；奖励三选一后固定海克斯三选一 |
| x-3 | 普攻小怪 | 敌人不会释放技能 / 终结技 |
| x-4 | 普攻小怪 | 同上，敌人更多 |
| x-5 | 挑战关 | 难度二选一：左 1–2 星 / 右 3–5 星；按掷出的星级发奖 |
| x-6 | 奖励关 | 2 只 1 血小怪；奖励三选一；「海克斯狂热」再送一次海克斯 |
| x-7 | BOSS | 第一试炼红青双子；第二试炼雷云巨像 |

- 非 BOSS 关失败：仍发**基础奖励**，扣征战生命后直接进入下一节点（不会卡关）。
- BOSS 关失败：发基础奖励并扣血；若 `hp >= 0` 保留当前阵容与敌人再战，直到击破或 `hp < 0`。
- 每个节点开战前玩家单位**满血**，不继承上一节点损失；`hp` 只代表整局征战生命。
- 胜利 / 失败都会在节点结束后按概率掉落装备；BOSS 胜利必掉 1 件进阶装备。

## 5. 卡牌、牌库与商店

### 5.1 牌库

- 初始牌库：每个 `POOL` 角色 9 张，共 90 张；`run.pool` 实时记录剩余。
- 购买、奖励卡、开局赠送都会从牌库扣除；出售按星级归还（1 星 1 张 / 2 星 3 张 / 3 星 9 张）。
- 商店一次展示 3 张，可重复角色；未购买的商品在刷新 / 进入下一节点时归还牌库。

### 5.2 价格与出售

| 项目 | 数值 |
|---|---|
| 1 星卡价格 | 4 金币 |
| 2 星卡价格 | 12 金币（3 张 1 星） |
| 商店刷新 | 2 金币 |
| 1 星出售 | 4 金币 |
| 2 星出售 | 12 金币 |
| 3 星出售 | 40 金币 |

### 5.3 自动升星

- 3 张同名同星 → 自动合成高 1 星；3 张 2 星 → 3 星。
- 升星优先保留战斗席上的那张；若高星卡在备战席、战斗席有同名低星卡，会自动互换，保证战斗席不重复角色。
- 合成时装备会并入目标卡；目标卡已有 3 件时，多余装备回到背包。
- 自动合成在购买、奖励卡、开局赠送后立即检查（`advCheckCombine`）。

### 5.4 战斗席 / 备战席

- 战斗席 3 格、备战席 6 格；1 张卡占 1 格，最多同时拥有 9 张卡。
- **战斗席不允许重复角色**（按 `POOL` 的 role key 判断；红青算 1 个角色、2 个单位）。
- 上阵 / 下阵 / 出售都走 `advPlaceOnBoard / advMoveToBench / advSellCard`；出售会返还装备。

## 6. 经济

每场战斗后结算：

| 项目 | 规则 |
|---|---|
| 基础奖励 | `6 + 节点序号 × 2 + (试炼-1) × 4`；失败也发 |
| 胜利奖励 | 胜利时 `4 + 节点序号` |
| 连胜奖励 | 胜利时 `min(5, 当前连胜)`；海克斯「连胜大师」再 +2 |
| 利息 | 胜利时 `min(5 + 利息上限加成, floor(金币/10))`，再乘利息倍率 |
| 失败扣血 | 小怪 10 / 挑战 12 / BOSS 18，再加 `星级 × 2`；第二试炼 BOSS 额外 +4 |
| 装备掉落 | 胜利 55% / 失败 25%；奖励关与 BOSS 胜利必掉；海克斯 / 环境可提高 |

- 利息只在胜利时结算；失败会把当前连胜清零。
- 金币奖励受「试炼枷锁」「双倍战利品」的倍率影响（奖励三选一）。
- 征战生命 `< 0` 才结束本局（等于 0 仍可继续）。

## 7. 海克斯

海克斯分**白银 / 黄金 / 棱彩**三档；`ADV_HEXES` 每档 5 个，共 15 个。

- 常规获取：1-2 / 2-2 奖励关后三选一；「海克斯狂热」在 1-6 / 2-6 再给一次。
- 品质权重：第一试炼约 60% 白银 / 32% 黄金 / 8% 棱彩；第二试炼约 32% / 46% / 22%；「彩虹时代」强制棱彩。
- **敌难**：默认 10；每 1 个黄金海克斯 +2，每 1 个棱彩 +5。敌难每比 10 高 1 点，普通敌人生命/攻击 +4%，BOSS 生命/攻击 +1.5%。

| 品质 | 海克斯 | 效果 |
|---|---|---|
| 白银 | 零钱袋 | 立即 +12 金币 |
| 白银 | 小算盘 | 利息上限 +2，立即 +4 金币 |
| 白银 | 磨刀石 | 所有角色伤害 +6% |
| 白银 | 轻羽 | 所有角色移速 +8% |
| 白银 | 急救包 | 立即回复 8 点征战生命 |
| 黄金 | 商人的直觉 | 商店刷新 30% 概率出现 2 星卡（价格 3 倍） |
| 黄金 | 铁匠铺 | 立即从 3 件基础装备中选择 1 件 |
| 黄金 | 连胜大师 | 连胜奖励 +2 |
| 黄金 | 团队护盾 | 所有角色开场 10% 最大生命护盾 |
| 黄金 | 黄金利息 | 利息收益 +50% |
| 棱彩 | 点金术 | 每个节点开始 +8 金币并掉 1 件随机基础装备 |

## 8. 装备

### 8.1 获取与装备

- **不再有装备商店 / Buff 商店**；装备只来自节点掉落、奖励三选一、环境「铁匠的馈赠」、海克斯「铁匠铺」/「点金术」。
- 装备进入 `run.inventory`；选中 1 件后点角色卡的「装备」即可装入该卡，每张卡最多 3 件。
- 已装备的装备可在角色详情里点图标卸下，回到背包。
- 出售角色卡时，卡上的装备会全部回到背包，不会丢失。

### 8.2 基础装备（5 件）

| 装备 | 效果 |
|---|---|
| 疾风鞋 | 移速 +12% |
| 锋刃小刀 | 普攻 / 技能 / 终结技伤害 +15% |
| 铁壁盾 | 防御 +25% |
| 生命花 | 最大生命 +22% |
| 剧毒药 | 持续伤害 +30% |

| 刀 + 盾 | 破军战刃 | 伤害 +35%，受伤 -5% |

| 盾 + 药 | 疫病壁垒 | 反弹 10% 伤害，持续伤害 +30% |

## 9. 战斗接入

- 玩家侧 `adventureOnUnitAdd()` 按「战斗席卡牌」聚合 `advCardStats(card)`：
  - 星级倍率（1 / 2 / 3 星）+ 装备 + 全局强化 + 海克斯；
  - 生命、攻击、防御、移速、伤害、持续伤害、吸血、回复、反伤、开场护盾、冷却流速；
  - 红青组合的两个单位共享同一张卡的面板。
- 敌方侧：
  - 普通小怪按 `ADV_STARS[star] × 节点倍率 × 敌难倍率` 缩放生命/攻击/防御/移速；
  - 1 血奖励怪强制 `maxHp = 1`；
  - 普攻小怪 `advNoSkill` 每帧压住技能 / 终结技 CD 与能量；
  - BOSS 走 `ADV_BOSS`，与普通 BOSS 的 `TYPES / BALANCE.boss` 完全分离。
- 伤害钩子：
  - `adventureDamageBefore`：玩家受伤减免、装备伤害 / DoT 增伤、护盾比例增伤、BOSS `pctOut`；
  - `adventureDamageAfter`：吸血、反伤、普攻减速；
  - `adventureOnTick`：回复、疾影层数、普攻小怪技能压制；
  - 百分比伤害（`opt.pct`）不吃过量增伤，遵守「不在 `hurt` 外另加倍率」红线。

## 10. BOSS

| BOSS | 形态生命（试炼 1 / 敌难 10） | atk / def / speed | pctOut |
|---|---|---|---|
| 红青双子 `duo` | 红 1500 / 青 1500 / 核心 1800 | 0.80 / 0.90 / 1.00 | 0.36 |
| 雷云巨像 `storm` | 一阶段 2400；二阶段 3600 | 0.72 / 0.92 / 1.00 | 0.50 |

- 第二试炼 BOSS 额外 ×1.30 生命与攻击。
- 敌难对 BOSS：生命 / 攻击 ×`1 + (敌难-10) × 1.5%`（最低 0.60），`pctOut` ×`1 + (敌难-10) × 1%`（最低 0.70）。
- 红青仍走引擎原有的「锁血 → 停手 → 靠拢 → 核心登场」三段；雷云仍走双血条转阶段。秘境只改数值，不改机制。
- 普通 BOSS 5v1 没有 `u.st.advBoss`，完全不受影响。

## 12. UI 与交互

- 顶部：试炼 / 节点、金币、征战生命、敌难、返回。
- 节点路径：两行 7 节点，标记已完成 / 当前 / BOSS / 挑战 / 奖励；未解锁的第二试炼降低透明度。
- 主区左侧：战斗席 3 格、备战席 6 格、选中卡详情（星级 / 面板倍率 / 装备）。
- 主区右侧：3 张商店卡 + 刷新、装备背包 + 合成、海克斯列表。
- 底部：当前节点说明、敌难、卡池剩余、连胜、开始战斗；挑战关给左右两个难度按钮。
- 结算 / 奖励 / 海克斯 / 装备选择 / 终局都是独立 `step`；刷新页面会回到对应 step，不会丢失。

## 14. 已知限制

- 商店展示的是 3 个独立槽位，允许出现重复角色；没有做「锁定单张商品」功能。
- 2 星卡只能在商店以 3 倍价格直接出现（海克斯「商人的直觉」），没有单独的「刷新必出 2 星」保底。
- 装备只能装在角色卡上，没有独立的装备栏 / 羁绊系统。
- 敌人阵容按节点随机从 10 个角色中抽取，不含装备；难度主要由星级、节点倍率与敌难承担。
- BOSS 失败可保留阵容再战，这是为了单机体验；如果连续失败，征战生命仍会耗尽。
- 手机端仍要求横屏；竖屏只做拦截提示。
- 普通对局的天气 / 食物仍会作用于秘境战斗，属于秘境难度的一部分，未做独立开关。
