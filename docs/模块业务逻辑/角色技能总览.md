# 角色技能总览（全部常规角色 + BOSS）

> **口径**：2026-11-24 当前代码。数据来源：`js/items/*.js`、`js/items/boss/*.js`、`js/items/pool.js`、`js/00-base.js` 的 `BALANCE`、`js/10-core.js` 的 `BOSS_ROLES`。
> **原则**：本文按**代码常量**记录；若代码内 `skill.text` 文案与常量不一致，以常量值为准，并在 [§4 文案差异](#4-代码常量与文案不一致) 单独列出。
> **维护**：改角色数值 / 技能 / 被动 / 狂暴后同步对应小节；新增角色时在 `POOL` 与本文 §1、§2 各加一条；新增 BOSS 时在 `BOSS_ROLES` 与本文 §3 各加一条。

## 0. 通用属性与伤害口径

### 0.1 面板属性

| 字段 | 含义 | 说明 |
|---|---|---|
| `key` | 单位 / 角色键 | 角色池用 `POOL[i].key`，单位用 `TYPES[key]` |
| `role` | 定位 | 例如「突刺 / 持续伤害」 |
| `r` | 碰撞 / 绘制半径 | 与场地的碰撞、命中判定共用 |
| `maxHp` | 最大生命 | 常规角色 2000 口径；草 2500、水桶 1800 |
| `baseSpeed` | 基础移速（px/s） | 平时匀速直线运动的速度 |
| `atk` | 攻击力 | 新体系统一 100，伤害由技能系数决定 |
| `def` | 防御 | 减伤 `DEF / (DEF + 400)` |
| `energyMax` | 终结技能量上限 | 常规角色统一 100；能量满后进入 0.4s 金色蓄力再释放 |
| `energyRegen` | 被动回能（每秒） | 部分远程角色有 |
| `bond` | 羁绊伙伴 | 目前只有红石块 ↔ 青金石块 |
| `calibrated` | 新数值体系标记 | `true` 时伤害**不再乘** `BALANCE.dmgScale = 1.6`（当前常规角色全部为 `true`） |
| `impact` | 是否参与撞击伤害 | 为 `true` 时碰撞才可能出伤；多数角色 `onAttack` 返回 0，伤害来自技能 |

### 0.2 伤害结算

| 环节 | 规则 |
|---|---|
| 撞击伤害 | `base = 2.2 + min(撞击速度, 620) × 0.05`，再乘攻击方 `atk × dmgMult`，最后走 `onAttack()` 覆盖 |
| 撞击窗口 | 同一单位两次撞击伤害至少间隔 `0.34s`；撞击速度低于 30 px/s 不结算 |
| 承伤修正 | 防御减伤 → 1v1 修正（当前表为空）→ `dmgScale`（仅未 `calibrated`）→ BOSS 承伤倍率；物品可用 `takenReduce` 声明**分类承伤减免**（当前只有咕咕嘎嘎：技能 -10% / 终结技 -20%，按 `opt.skill` / `opt.ult` 标记生效） |
| 统一入口 | `hurt(u, amount, src, opt)`：护盾吸收 → 扣 HP → 死亡触发羁绊 / 复活等；`dealt` 只累计实际 HP 损失，`taken` 含护盾吸收但两者都不计溢出 |
| 伤害分类 | 所有实际伤害至少带一个标记：`basic` 普攻 / `skill` 技能 / `ult` 终结技 / `dot` 持续伤害；分类可组合，例如技能型 DoT 为 `{skill:1, dot:1}` |
| `opt.pct` | 百分比伤害：凡按最大生命计算（目标生命或施放者生命均算），不乘 `dmgScale` 与食物攻击，并走 BOSS `pctTakeMul` 承伤口径 |
| `opt.periodic` | 周期跳伤表现：不逐跳播特效，每满 1 秒汇总一条飘字；与 `opt.dot` 分类已解耦 |
| `opt.basic` | 标记本次伤害来自**普通攻击**；青金石狂暴天赋据此减免 60% |
| 多目标衰减 | 同一次范围效果命中 N 人：每人 `0.72^(N-1)`（1 人时 100%） |

### 0.3 狂暴（羁绊）

- 触发：红石块 / 青金石块其中一方阵亡 → 幸存者原地**无敌抖动 3 秒** → 进入 `rage`。
- 狂暴期间：移速按 `rage.speedMul` 固定 ×3；红石可穿透敌方，青金石保留实体碰撞。
- 狂暴前 3 秒抖动：速度 0、免疫伤害、不能行动。
- 其他角色没有 `bond` / `rage`，阵亡不会触发狂暴。

## 3. BOSS 模式单位（5v1，不在 `POOL`）

> BOSS 战时长固定 300s，舞台整局不收缩。BOSS 承伤：非百分比伤害 ×0.79、百分比伤害 ×0.20；BOSS 出手不做整体缩放，技能系数即最终伤害。挑战者不加任何数值。
> 可选 BOSS 由 `BOSS_ROLES` 决定：`duo`（红青双子 → 紫晶核心）、`storm`（雷云巨像）。
> **秘境试炼是独立模式**：第一试炼 BOSS 红青、第二试炼 BOSS 雷云，走 `ADV_BOSS`（红 6,500 / 青 6,500 / 核心 7,000，总 20,000；雷云一阶段 20,000 + 二阶段 30,000，总 50,000）。攻击面板 = 基础攻击 × `ADV_BOSS.atk`（红青 1.60 / 雷云 1.44）× 第二试炼 1.30 × 敌难倍率；2-7 最终 BOSS 击破直接通关结算，不发战利品。本节 5v1 的 TYPES / BALANCE 数值不被秘境反向修改。详见 [秘境闯关](秘境闯关.md)。
