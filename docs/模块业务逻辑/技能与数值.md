## 1. 模块职责与边界

| 职责 | 说明 | 关键位置 |
|---|---|---|
| 数值配置 | 公式常量 `BALANCE` + 每个物品的完整定义 `TYPES` | `index.html:383-678` |
| 角色池 | `POOL` 定义可选角色；红/蓝双方各选 1 个角色 | `index.html:679-715` |
| 派生伤害 | `dmgOf()`：撞击速度 + 攻击方 `onAttack` + 承受方 `onDamaged` | `index.html:762-770` |
| 技能释放 | 通用转向 + 冲刺 + 冷却，再调用物品 `onCast` | `index.html:1390-1403` |
| 技能施放 | **CD 好了先 0.16s 蓄力，再释放**；冲刺型贴脸（<55px）时跳过 | `js/30-sim.js` |
| 羁绊狂暴 | 一方阵亡 → 幸存者原地无敌抖动 3s → 狂暴（移速 ×3） | `index.html:1155-1186` |
| 伤害结算 | 无敌判定、护盾吸收、扣血、死亡触发羁绊 | `index.html:1085-1123` |
| 回合判定 | 一方角色内所有单位合计血量归零 / 决杀扣血 / 双杀按累计伤害 | `index.html:1576-1635` |

**本模块不做的事：**

- 不负责位移（在 `move()`）；技能只改 `ang` 与 `dashT`。
- 不负责播放音效（音效由 `js/50-ui.js` 的 `sfxPlay()` 统一处理，本模块只调用钩子）。
- 不做 AI 距离/角度/反应判断：CD 好了就蓄力释放（仅冲刺技能会跳过 <55px 的贴脸距离）。
- 不固化阵营：由 `pick` 决定双方角色，`TYPES` 里只有 `bond` 关系。

### 2.5 对战模式与阵容（2026-11-6 第 50 条，第 51 条改为两维设置）

模式由**两个独立开关**决定（`js/10-core.js` 的 `teamSize` + `modeKind`）：

| 开关 | 取值 | 位置 |
|---|---|---|
| 人数 `teamSize` | 1 / 2 / 3 | `#modePick` 第一行 |
| 上场方式 `modeKind` | `vs` 同时上场 / `relay` 接力 | `#modePick` 第二行 |

**组合规则**

| 人数 | 同时上场 | 接力 |
|---|---|---|
| 1v1 | ✅ 默认 | ❌ **按钮置灰**（只有一个角色，没有"下一个"） |
| 2v2 | ✅ | ✅ |
| 3v3 | ✅ | ✅ |

- 切换人数时，若降到 1v1 会**强制回到同时上场**；不够的格子用角色池里还没用过的角色自动补齐。
- **同时上场**：该方每个角色的**所有单位**一起进场（红青组合算 1 个角色，但占 2 个单位）。
- **接力**：先只进第 1 个角色；其单位**全部阵亡**后 1.0s 放第 2 个，再死后放第 3 个。

**接力的关键约定**

- **胜者保留一切**：血量、护盾、冷却、狂暴状态都保持不变，由同一个单位继续打。
- **败者换人**：新角色在自己半场随机出生，满血、冷却重新随机。

- **护盾从 70 上调到 500**：初始按用户给定值 70 实现时，一次普通命中就会打空，领域几乎只结算「展开瞬间」这一跳，1v1 总体胜率仅 **1.6%**。按平衡目标把 `shieldMax` 提到 **500** 后回到可用区间；7% 伤害比例与 12s 冷却均未改。改为「结束后重算 CD」后，864 局矩阵总体 **43.8%**、平均单局 34.2s（旧的无缝口径约 45%~46%）。
- **召唤物范围**：只包含 `seeds`（草的种子）。种子没有护盾 / 无敌，走 `hurtSeed()` 按 `maxHp × 7%` 扣血，伤害计入狗奶的 `dealt`。
- **决杀例外**：`deathStrike()` 不走 `hurt()`，所以领域中的狗奶仍按 5%/s 掉血（与"决杀绕过护盾 / 无敌"的既有规则一致）。
- **渲染**：领域中沿用 `drawMilk()` 的金色脉动环 / 虚线环 / 上升奶滴，以及 `drawMilkLinks()` 拉向每个敌人与敌方种子的流失连线；血条下方显示 500 点护盾条。

## 3. 核心流程

### 3.1 一次撞击

```text
move() → collide() 圆重叠
  → 位置分离（抖动单位不动）
  → 算 rel / impact
  → impact 足够且 hitCd 就绪：
      → dmgOf(b, …) → hurt(a) → 死亡触发羁绊
      → dmgOf(a, …) → hurt(b)
      → onHit（红石溅射）
  → 否则只弹开
```

### 3.2 技能施放（`js/30-sim.js`）

**规则：技能 CD 好了先进入 0.16s 蓄力预警，再释放；冲刺型技能贴脸时不放。**

| 顺序 | 条件 | 行为 |
|---|---|---|
| 0 | 已死 / 狂暴 / 冲刺中 / CD > 0 / 蓄力中 | 返回 |
| 1 | 没有存活敌人 | 返回 |
| 2 | `canCast(u)` 返回 false（草） | 返回，不消耗 CD |
| 3 | 冲刺技能且距离 < 55px | 返回，等拉开距离 |
| 4 | CD 已归零且条件通过 | 锁定目标当前位置 `castAim`，`castT = 0.16` |
| 5 | `updateCasts()` 把 `castT` 递减到 0 | `cast(u, castAim)`，方向在蓄力开始时已锁定 |

> 蓄力期间目标可以走开，因此观众有 0.16s 的反应窗口；`drawUnit()` 会画虚线 + 落点圈。
> 旧版"防僵局"（超过 3.2s 无撞击就全体 `cd = 0`）已删除。这是长矛连续冲刺的根因：长矛普通撞击无伤害，计时器几乎必然触发，导致冲刺刚结束就再次施放。现在 `cd` 只由 `cast()` 设置、由 `tick()` 自然递减。

**结论**

2. **对铁砧反而变弱（−6.3）**：铁砧是本池唯一的"纯 AoE 落点"，现在每 3 秒就能顺手把种子砸碎（溅射 105），草失去一次复活；这是本次改动**唯一明确的代价**，也说明"种子可被 AoE 击杀"确实生效了。
3. **对弓箭几乎无变化（+1.3）**：弓箭的箭会命中种子，但普通箭命中种子即消失，等于偶尔"浪费一发"；草依然被远程压制（1.8%）——这是草的老问题（300 HP / 200 px/s、射程 220 够不到），不是种子能解决的。

5. **强度判断**：草仍属**偏弱档**（平均 35.6%，仅对红青 81.5% / 冰块 72.8% 占优），本次改动没有把它推成上位角色，不需要回调；若后续想让草更强，优先动**本体**（HP / 移速 / 捆绑射程），而不是继续加种子收益。
6. **可选微调旋钮**（本次均未采用）：`seed.hp` 100 → 80（削弱对冰块 / 大狗），`healPerSec` 5 → 3（削弱续航），`healRadius` 200 → 150（要求草贴种子打）。
